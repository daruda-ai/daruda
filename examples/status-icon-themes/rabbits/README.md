# Rabbits

A long-eared rabbit status icon theme for daruda. Stable selection ID:
`user/rabbits`.

In Settings → Workspace → Sidebar → Status icon theme, choose **Open theme
folder**, copy this entire directory into it, then select **Rabbits · user/rabbits**.
Keep `theme.json` and every SVG file together. See the [theme format](../README.md)
for profile paths and layer support.

| State | Pose |
|---|---|
| Disconnected | Empty burrow |
| Connecting | Long waking stretch |
| Working | Cheerful left-facing hop |
| Executing tool | Digging with the front paws |
| Needs attention | Raised front paw and one softly bent ear |
| Idle | Resting low with ears laid back |
| Completed | Upright pose with tall ears and quiet smiling eyelids |
| Errored | Wide-eyed surprise with swept-back ears |
| Failed | Low crouch with folded ears |

All nine poses are static. Small side-set eyes and short eyelids distinguish
the rabbit from the kitten and puppy. Fixed white facial layers remain opaque
in both appearances; the body uses state colors with a deeper Working blue in
dark appearance. Every mask shares a 16 × 16 view box for 16px/12px rendering.

The character sheet was created with AI image generation and converted to
self-contained SVG paths.
