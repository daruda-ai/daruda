# Dogs

A floppy-eared puppy status icon theme for daruda. Stable selection ID:
`user/dogs`.

In Settings → Workspace → Sidebar → Status icon theme, choose **Open theme
folder**, copy this entire directory into it, then select **Dogs · user/dogs**.
Keep `theme.json` and every SVG file together. See the [theme format](../README.md)
for profile paths and layer support.

| State | Pose |
|---|---|
| Disconnected | Empty kennel |
| Connecting | Play-bow stretch |
| Working | Cheerful left-facing trot |
| Executing tool | Digging with the front paws |
| Needs attention | Seated with one front paw raised |
| Idle | Chin resting on the front paws |
| Completed | Upright smile with two matching relaxed eyelids |
| Errored | Wide-eyed surprise |
| Failed | Low crouch with drooping ears |

All nine poses are static. Rounded eyes, a broad nose and a separate muzzle give
the puppy its canine expression. Fixed white facial layers remain opaque in
both appearances; the body uses state colors with a deeper Working blue in dark
appearance. Every mask shares a 16 × 16 view box for 16px/12px rendering.

The character sheet was created with AI image generation and converted to
self-contained SVG paths.
